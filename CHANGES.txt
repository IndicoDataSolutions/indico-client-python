Oct 16 2019 v2.0.0: Complete change of IndicoIo API through the Indico IPA platform. For IPA Platform API use only.
Mar 13 2026 Unreleased: Support matching release tags that include dotted PEP 440 suffixes (for example `7.9.0.post1`) in dynamic versioning.
Oct 29 2026 Unreleased: Model export downloads (`DownloadModelExport`, `GetModelExports(with_download_url=True)`, `CreateModelExport(wait=True)`) use the platform's `downloadUrl` and `UploadStaticModelExport` uploads through the authenticated client session. `with_signed_url` is deprecated, now selects `downloadUrl`, and `ModelExport.signed_url` is always None. `DownloadModelExport` raises `IndicoInputError` when the export has no `download_url`. These transfers refuse redirects, and uploads have no total timeout, only a 600s read timeout.
