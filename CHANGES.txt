Oct 16 2019 v2.0.0: Complete change of IndicoIo API through the Indico IPA platform. For IPA Platform API use only.
Mar 13 2026 Unreleased: Support matching release tags that include dotted PEP 440 suffixes (for example `7.9.0.post1`) in dynamic versioning.
Oct 29 2026 Unreleased: Model export downloads (`DownloadModelExport`, `GetModelExports(with_download_url=True)`, `CreateModelExport(wait=True)`) use the platform's `downloadUrl` and `UploadStaticModelExport` uploads through the authenticated client session. `with_signed_url` is deprecated, now selects `downloadUrl`, and `ModelExport.signed_url` is always None. `DownloadModelExport` raises `IndicoInputError` when the export has no `download_url`. These transfers refuse redirects. The model export upload and download send no client timeout (aiohttp's 300s default would cut off large files). A missing `uploadUrl` from the platform raises `IndicoRequestError` instead of an `AttributeError`.
Nov 02 2026 Unreleased: Added `UploadFieldBlueprints` (uploads a field blueprint import file through the authenticated client session, optionally running `ImportFieldBlueprints`) and `DownloadFieldBlueprintExport` (fetches the `download_url` of a finished `ExportFieldBlueprints` job and returns the parsed export). Both refuse redirects and accept only `/storage/` paths from the platform. The HTTP clients now take the JSON and gzip suffix from the URL path only, so a query string like `?name=<uuid>.json` no longer forces JSON decoding of an HTML error page.
